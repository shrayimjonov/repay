# card

Card service. Links customer cards (Humo, Uzcard, Visa, Mastercard), keeps card tokens, checks balances.

Stack: Java 21, Spring Boot 3.1.7, PostgreSQL, MongoDB, Kafka, Redis, Liquibase, OpenFeign, Quartz, Maven.

Run:

```bash
./mvnw spring-boot:run
```

Settings come from environment variables.
